## Redirect Logic

```
1. Auth loading/error → null (stay put)
2. Not logged in + not on /login → redirect /login
3. Logged in + on /login → redirect /main
4. Logged in + on /dashboard → redirect /main  (legacy redirect)
5. /admin/* + !isAdmin → redirect /main  (admin guard)
6. Default → null (no redirect)
```

## Admin Gating

- **Router layer**: `state.uri.path.startsWith('/admin')` → redirect if `!isAdmin`
- **UI layer**: `ref.watch(authProvider).value?.isAdmin` controls visibility
- **Admin routes**: `/admin/ledger/health`, `/admin/ledger/drift`, `/admin/uom-diagnostics`

## Auth Mechanism

- `appRouterProvider` watches `authProvider` (Riverpod `AsyncNotifier`)
- `refreshListenable`: `_AuthStateListenable` wraps `AsyncValue<AuthState>`
- Token stored in `FlutterSecureStorage`
