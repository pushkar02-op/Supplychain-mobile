## Implementation Summary

### ORD-007 — Dispatch Must Respect Order Remaining Quantity

**Enforcement Point:** `app/services/dispatch_entry.py:create_dispatch_entry`

**Logic Added:**
1. Query active orders (item_id, mart_id, status not Cancelled/Completed)
2. Calculate remaining: `quantity_ordered - quantity_dispatched`
3. If `dispatch_qty > remaining_qty` → 409 Conflict with ORD-007 metadata
4. Block dispatch against Cancelled/Completed orders
5. No inventory mutation on failure
