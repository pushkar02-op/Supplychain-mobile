---
name: ux-copy-truthfulness
description: Ensures UI copy explains real system behavior accurately.
---

## When to use
Trigger when:
- Error messages added
- Confirmation dialogs designed

## Strategy
1. Replace generic errors with actionable copy.
2. Explain cause + resolution.
3. Avoid blame language.

## Validation
• User knows what to do next  

## Failure Modes
• "Something went wrong"  

Why this Skill exists

Misleading copy caused user confusion even when logic was correct.
