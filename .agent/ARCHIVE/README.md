# .agent/ARCHIVE/ — Superseded Artifacts

Files that were canonical at some point but have been replaced by
newer versions. Preserved for historical reference.

## Status
EMPTY — will grow as the repo evolves.

## What Goes Here
- Old ADRs that have been superseded (with a reference to the new one)
- Old session files older than ~90 days (after they're no longer relevant)
- Old prompt templates replaced by newer ones

## What Does NOT Go Here
- Anything currently referenced by live processes
- Anything newer than 30 days (too recent to archive)
- Code or config files (those belong elsewhere in the repo)
