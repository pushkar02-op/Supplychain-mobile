# .agent/DECISIONS/ — Architecture Decision Records (ADRs)

This directory holds immutable records of architectural decisions made
over time. Once written, an ADR is never edited — only superseded by
a new ADR.

## Status
EMPTY — first ADRs will be written during the Documentation Rewrite
Project.

## Format
Each ADR is a numbered markdown file: `0001-title-of-decision.md`.

## How to Use
When making a decision that affects architecture, write a new ADR
here before (or immediately after) implementing the change. Reference
the ADR number in commit messages and code comments.
